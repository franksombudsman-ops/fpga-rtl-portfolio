# ZCU104 FPGA / SoC Engineering Series

This directory contains FPGA and heterogeneous SoC engineering projects
implemented on the AMD ZCU104 development platform.

The series progresses from deterministic RTL control architectures through
hardware interfaces, timing closure, embedded instrumentation, AXI-based
processor/programmable-logic integration, Linux-controlled custom hardware,
high-throughput datapaths, and ASIC-oriented reusable RTL IP.

## Engineering Platform

- Platform: AMD ZCU104
- Device family: Zynq UltraScale+ MPSoC
- Development environment: AMD Vivado / Vitis 2023.2
- RTL: SystemVerilog
- Embedded platform: PetaLinux 2023.2

## Project Series

1. Deterministic Event & Control Engine
2. Precision PWM & Motor Control Engine
3. Sensor Interface Engine
4. Hardware Measurement & Frequency Capture Engine
5. AXI4-Lite Custom Peripheral
6. DMA / High-Throughput Data Engine
7. Interrupt-Driven PL/PS System
8. Linux-Controlled Custom Hardware
9. Streaming DSP Architecture
10. Advanced Heterogeneous SoC System
11. ASIC-Oriented Reusable RTL IP
12. ASIC Implementation and Timing Flow

Each project is developed using a specification-driven workflow incorporating
RTL design, verification, synthesis, implementation, timing analysis,
physical hardware validation, instrumentation, and engineering documentation.
